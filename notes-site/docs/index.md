# Introduction

Welcome — this is my personal zettelkasten, a running collection of notes I take as I listen, watch, attend lectures, and read. It's organized so any note stands on its own, but related ideas link to each other over time.

The wiki is meant to be read [in the web format](https://beyondgoodevil.github.io/memorabilia/).

## How it's organized

!!! info "Three main sections"
    - **Podcast/Video Notes** — takeaways from podcast episodes and YouTube videos, grouped by show or channel.
    - **Lecture Notes** — notes from courses and lectures, grouped by class.
    - **Book Notes** — one page per book, expanded chapter by chapter as I read.

Use the sidebar on the left to browse by section, or the search bar at the top to jump straight to a topic. Every note has its own table of contents on the right for quick navigation within long pages.

## How notes get published

Notes live as plain markdown files in this repository. Whenever a new note is pushed to `main`, the site rebuilds and redeploys automatically — so there's no separate publishing step beyond writing and pushing.

## Contributing / feedback

If you spot an error or want to suggest something, open an [issue](https://github.com/beyondgoodevil/memorabilia/issues) or use the edit pencil at the top of any page.
